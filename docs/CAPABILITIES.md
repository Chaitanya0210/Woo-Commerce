# Capabilities

- `list_orders`: Retrieve a paginated list of orders.
- `search_orders`: Search orders using WooCommerce text search.
- `get_order`: Retrieve a specific order by ID.
- `list_products`: Retrieve a paginated list of products.
- `search_products`: Search products by keyword/sku.
- `get_product`: Retrieve a specific product by ID.
- `check_stock`: Fast subset query for product stock status.
